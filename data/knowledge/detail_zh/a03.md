## 介绍

计算机模拟作为科学家和工程师的强大工具，使他们能够深入了解复杂系统（Santner 等，2018；Gramacy，2020）。计算机实验比物理实验成本更低，有时涉及大量试验。大规模实验引入了显著的计算挑战，尤其是在实验设计的构建和后续模型拟合过程中。本文介绍了旨在克服这些挑战的新型实验设计方法。拉丁超立方设计（LHD）（McKay 等，1979）是计算机实验中最广泛使用的实验设计类型。当输入因素呈稀疏性时，它们尤其具有吸引力，因为它们均匀覆盖每个单独因素的区域（Morris 和 Mitchell，1995）。具有额外空间填充特性的 LHD，如低差异（Fang 等，2018）、高分离距离或低填充距离（Johnson 等，1990），在大多数或所有输入都有影响时，比随机 LHD 更理想。生成空间填充 LHD 有三种主要方法。第一种方法涉及代数构造方法，由 Tang（1993）、He 和 Tang（2013）、Xiao 和 Xu（2017）、Xiao 和 Xu（2018）、Zhou 等（2020）提出。这些方法计算效率高，因此适合构建大规模设计。然而，它们对样本量 n 和因子数 d 有严格约束。因此，更广泛使用的方法是对 LHD 的特定空间填充特性进行数值优化（Morris 和 Mitchell，1995）。然而，数值优化算法在构建大规模设计时计算效率低下。

由于优化问题的高维性质，其中包含大量局部最优解。鉴于有限的计算资源，找到最优或接近最优的解本质上是困难的。

<!-- page: 3 -->

第三种方法将搜索限制在良格点集（GLP）（Korobov, 1959），它们是具有格点结构的拉丁超立方体设计（LHD）的一种特定类型。格点约束提供了两个主要优势：首先，格点结构有利于不确定性量化，特别是在某些输入或模型参数具有已知先验分布时估计输出分布（Hua 和 Wang, 1981；Sloan 和 Joe, 1994）。此外，施加格点约束显著减少了搜索空间，使得数值上更容易识别高质量设计。尽管有这些优势，对于大 n 值，仍然存在许多不同的格点集，使得识别最优集合具有挑战性。Korobov（1959）建议对所有幂生成器进行穷举搜索，因为由此类型生成器生成的格点集通常显示出低离散度。然而，搜索选项过少会增加错过最优设计的可能性。最近，Vazquez 和 Xu（2024）提出了一种整数规划算法，旨在最大化 GLP 的分离距离。然而，该方法侧重于 n 小于等于 113 的情景。最后，Zhou 和 Xu（2015）、Wang 等（2018）、Sun 等（2019）、Wang 等（2022）等人提出了构造具有卓越分离距离或离散度的 GLP 的代数方法。然而，与非格点 LHD 的代数构造类似，这些方法仅适用于特定的 n 和 d 值。

在本研究中，我们提出了用于计算 GLP 分离距离、离散度和投影特性的新的快捷公式。通过降低计算复杂性

(SG) 由 Plumlee (2014) 提出，使用单一的全局模型进行预测，基于所有 n 个观测值。由于 SG 需要设计为稀疏网格并对 n 施加约束，我们分别对三个测试函数使用 n = 4089、8361 和 40081，因为这些数值是允许的最近大小。  

我们假设尺度参数未知，需要在拟合模型之前进行估计。对于 PD、NN、laGP 和 SG，我们通过最大化似然函数来估计尺度参数，这与 Gramacy 和 Apley (2015) 以及 Plumlee (2014) 所做的方法一致。虽然这样可以得到准确的尺度参数，但需要多次数值优化迭代，每次迭代都涉及相关矩阵的逆运算。因此，估计尺度参数所需的计算量显著高于模型拟合。  
对于大规模仿真问题，我们建议使用较小的子设计来估计尺度参数。根据定理 3.6，对于小于 n 的任何整数 q，R(n, m, v, δ) 包含许多互为平移的 q 点局部设计。在 RLHD 方法中，我们随机生成 10 个 q = 50 点的局部设计。然后通过在这 10 个设计上最大化复合似然来估计尺度参数。由于所有 10 个设计互为平移，每次迭代只需要对 q × q 的相关矩阵进行一次逆运算。由于 O(q³) 远小于 O(m³)，RLHD 方法中估计尺度参数所需的计算量显著低于模型拟合。因此，RLHD 比 PD、NN 和 laGP 更加高效。

5 结论

在本文中，我们提出了用于高效生成任意 n 和 d 的填充空间设计的新方法。关键创新是使用新的捷径公式，将计算复杂度从 O(n²) 降低到 O(n) 和 O{log(n)}。由于所构建设计在数值积分问题上非常有吸引力，它们在拟合 PINNs 时表现出色。未来的工作需要验证这些设计是否对其他深度学习问题有用。

我们还引入了一种构建规则重复设计的方法，该设计包含许多局部填充空间的 LHD 作为子设计。这些设计结合移动窗口类型的局部建模技术，有助于快速拟合高斯过程仿真器。尽管我们主要关注中等耗时的计算机仿真，在这些情况下可以进行数百或数千次仿真试验，我们的方法能够构建极大的设计，并可应用于其他统计领域的一般黑箱函数。我们提出的设计的规则重复结构源于其基于格的结构。构建规则重复的设计可能是可行的。
